# trainer.moscow

Сайт репетиторов и тренеров в Москве: каталог, анкеты специалистов, заявки на занятия и личный кабинет.

## Разделы

| Адрес | Что там |
|---|---|
| `/` | Главная: анкета Руслана Алиева на первом экране, занятия и цены, отзывы |
| `/repetitory` | Репетиторы |
| `/repetitory/ruslan-aliev` | Анкета Руслана Алиева с формой записи |
| `/trenery` | Тренеры (пока анкет нет — страница закрыта от индексации и откроется сама) |
| `/zanyatiya`, `/zanyatiya/<предмет>` | Занятия, форматы и цены |
| `/kabinet` | Личный кабинет: заявки, анкета, статистика, настройки, модерация (для админа) |
| `/kabinet/registraciya` | Регистрация нового специалиста (анкета публикуется после модерации) |

## SEO

- Серверный рендеринг, у каждой страницы свои title, description, canonical, Open Graph.
- Разметка schema.org: WebSite, Organization, ProfilePage + Person, BreadcrumbList, ItemList.
- `robots.txt` (кабинет закрыт, Clean-param для Яндекса) и `sitemap.xml` строятся автоматически из опубликованных анкет.
- Пустые разделы и анкеты на проверке отдаются с `noindex`.
- IndexNow: после выкладки новой версии сайт сам сообщает Яндексу об адресах из карты сайта.
- 301-редиректы: `www` → без `www`, адреса со слешем в конце → без слеша.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `DATABASE_URL` | PostgreSQL. Без неё данные пишутся в `data/db.json` (для локальной разработки) |
| `SITE_URL` | Основной адрес, по умолчанию `https://trainer.moscow` |
| `ADMIN_PASSWORD`, `RUSLAN_PASSWORD` | Пароли для первого входа (`admin`, `ruslan`). Используются только при создании учётки, дальше пароль меняется в кабинете |
| `SESSION_SECRET` | Ключ подписи сессий (если не задан — создаётся и хранится в базе) |
| `YANDEX_VERIFICATION`, `GOOGLE_SITE_VERIFICATION` | Коды подтверждения сайта в Яндекс Вебмастере и Google Search Console |
| `YANDEX_METRIKA_ID` | Номер счётчика Яндекс Метрики |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Уведомления о новых заявках в Telegram (необязательно) |
| `INDEXNOW_KEY` | Ключ IndexNow для Яндекса (файл `/<ключ>.txt` отдаётся сайтом автоматически) |
| `INDEXNOW_DISABLED=1` | Временно не сообщать Яндексу о страницах (например, пока домен не привязан) |

## Запуск

```bash
npm install
ADMIN_PASSWORD=... RUSLAN_PASSWORD=... npm start   # http://localhost:3000
npm run check                                      # быстрая проверка страниц, заявки и кабинета
```

Деплой — Docker (`Dockerfile`), Node 22.

Шрифты Golos Text и Unbounded — OFL 1.1, лицензии в `public/fonts`.
