# trainer.moscow — Shatova Pro

Сайт Евгении Шатовой — онлайн-тренера и тренера по позированию (IFBB Pro Bikini). Онлайн-ведение, позирование, подготовка к соревнованиям, продажа доступа к программам тренировок и питания, команда тренеров и личный кабинет.

## Разделы

| Адрес | Что там |
|---|---|
| `/` | Главная о Евгении: форматы, как это работает, программы, путь на сцену, позирование, команда, вопросы, заявка |
| `/programmy`, `/programmy/<код>` | Форматы и программы с тарифами, кнопкой «Купить» или предзаписью |
| `/zakaz/<код>/<тариф>`, `/zakaz/status/<id>` | Оформление и статус заказа (ЮKassa или ручная оплата) |
| `/trenery`, `/trenery/<код>` | Тренеры и анкеты |
| `/zanyatiya`, `/zanyatiya/<направление>` | Направления для поиска |
| `/kabinet` | Кабинет: ученик — «Мои программы» и уроки; тренер — заявки, анкета, фото; админ — ещё заказы, форматы и программы, модерация |

Старые адреса репетиторов (`/repetitory…`, `/zanyatiya/geografiya…`) отдают 301 на новые разделы.

## Как продавать программу

1. Кабинет → «Форматы и программы» → программа.
2. Заполнить тарифы: `код | название | цена | старая цена | занятий | дней доступа | примечание`.
3. Добавить уроки: `## Модуль`, `### Урок | ссылка на видео` (YouTube, Rutube, VK Видео, Kinescope), ниже — текст.
4. Статус «Продаётся». Пока цены нет — на сайте «по запросу», кнопки «Купить» нет.

После оплаты (ЮKassa) доступ открывается автоматически. Без ЮKassa заказ приходит со статусом «Ждёт оплаты» — админ отмечает оплату в «Заказах».

## Telegram-бот и группа поддержки

Устроено как в HelpMame: каждый клиент — отдельная тема в группе поддержки со значком по цели (🔥 тело, 🤰 после родов, 🏆 сцена, 💃 позирование, 💰 заказ, 📆 предзапись, 💬 вопрос).

- В тему клиента попадают заявки с сайта, предзаписи, заказы и оплаты, сообщения из лички бота и ответы AI-ассистента.
- Тренер пишет ответ прямо в тему — бот копирует его клиенту в личку (текст, фото, видео, голосовые). `/close` — завершить разговор, `/ai` — снова включить AI-ассистента.
- В боте: приветствие с картинкой (фон `public/img/bot-welcome-*.png` + фото со сцены из медиатеки, собирается на сервере), кнопка «Бесплатная консультация» → цель → номер телефона кнопкой. Заявка из бота появляется и в кабинете.
- После заявки на сайте — кнопка «Получать ответ в Telegram»: бот привязывает Telegram к теме заявки.
- Аватар бота, описание, команды и кнопка меню ставятся автоматически при запуске (`src/bot.js → setup`).
- Группа: темы включены, бот — администратор с правом «Управление темами». Если группа стала супергруппой и сменила id, бот запомнит новый сам.
- Вебхук ставит панель RelaxNet через приёмник → `/api/telegram/webhook`, проверка секрета `TELEGRAM_WEBHOOK_SECRET`.

Код: `src/telegram.js` (Bot API через прокси), `src/support.js` (темы), `src/bot.js` (бот), `src/ai.js` (AI-ассистент).

## Переменные окружения

Необязательные переменные (их может не быть в настройках RelaxDev) читаются только через `env('ИМЯ', по_умолчанию)` из `src/env.js`, то есть `process.env[name]`. Запись `process.env.ИМЯ` — только для переменных, которые заданы в проекте: для остальных RelaxDev подставляет заглушку, и значение по умолчанию не срабатывает.

| Переменная | Зачем |
|---|---|
| `DATABASE_URL` | PostgreSQL. Без неё данные пишутся в `data/db.json` (для локальной разработки) |
| `SITE_URL` | Основной адрес, по умолчанию `https://trainer.moscow` |
| `ADMIN_PASSWORD`, `SHATOVA_PASSWORD`, `DARYA_PASSWORD`, `EROKHIN_PASSWORD` | Пароли для первого входа (`admin`, `shatova`, `darya`, `erokhin`). Используются только при создании учётки, дальше пароль меняется в кабинете |
| `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` | Онлайн-оплата через ЮKassa. Уведомления: `https://trainer.moscow/api/yookassa` (событие payment.succeeded) |
| `YOOKASSA_RECEIPT=1`, `YOOKASSA_VAT_CODE` | Чеки 54-ФЗ через ЮKassa (если касса подключена там) |
| `SELLER_NAME`, `SELLER_INN`, `SELLER_EMAIL` | Реквизиты продавца для публичной оферты |
| `SESSION_SECRET` | Ключ подписи сессий (если не задан — создаётся и хранится в базе) |
| `YANDEX_METRIKA_ID` | Номер счётчика Яндекс Метрики |
| `TELEGRAM_BOT_TOKEN` | Бот заявок и поддержки |
| `TELEGRAM_SUPPORT_CHAT_ID` | Группа поддержки с темами (бот — админ с правом «Управление темами») |
| `TELEGRAM_WEBHOOK_SECRET` | Секрет вебхука: без него вебхук ничего не принимает |
| `TG_PROXY_URL`, `EGRESS_PROXY_URL` | HTTP-прокси для api.telegram.org и api.anthropic.com (из России напрямую не открываются) |
| `ANTHROPIC_API_KEY`, `AI_REPLIES=0` | AI-ассистент в боте (модель claude-sonnet-5-5 задана в `src/ai.js`); без ключа молчит, `AI_REPLIES=0` выключает |
| `INDEXNOW_KEY` | Ключ IndexNow для Яндекса (файл `/<ключ>.txt` отдаётся сайтом автоматически) |

Подтверждение сайта в Яндекс Вебмастере и Google Search Console — файлами в `public/` (`yandex_….html`, `google….html`).

## Запуск

```bash
npm install
ADMIN_PASSWORD=... npm start   # http://localhost:3000
npm run check                                      # быстрая проверка страниц, заявки и кабинета
```

Деплой — Docker (`Dockerfile`), Node 22.

Шрифты Golos Text и Fira Sans Extra Condensed — OFL 1.1, лицензии в `public/fonts`.
